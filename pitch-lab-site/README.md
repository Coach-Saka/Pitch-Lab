# Pitch Lab — 配布手順

`index.html` を Web に置いて、選手にURLを1本配るための手順です。

このフォルダの中身：

| ファイル | 中身 |
|---|---|
| `index.html` | アプリ本体。これ1つで完結しています |
| `rapsodo-template.csv` | CSV取り込みの見本 |
| `README.md` | このファイル（アップロード不要） |

---

## 0. 前提：このファイルについて

- **サーバー不要・ビルド不要。** 外部スクリプト、CSS、フォント、CDN参照、通信はすべてゼロです。
- ダブルクリックして開くだけでも動きます（オフラインでも動作）。
- データは **選手それぞれの端末のブラウザに自動保存** されます。どこにもアップロードされません。
- `index.html` という名前は変えないでください。Web サーバーはこの名前をトップページとして配信します。

---

## 1. GitHub Pages で公開する（おすすめ・無料）

一度設定すれば、以後はファイルを差し替えるだけで全員が最新版になります。

1. [github.com](https://github.com) でアカウントを作る（無料）
2. **New repository** → 名前を `pitch-lab` などにして、**Public** を選んで作成
3. リポジトリの画面で **Add file → Upload files**
4. `index.html` と `rapsodo-template.csv` をドラッグして **Commit changes**
5. **Settings → Pages** を開く
6. *Build and deployment* の *Source* を **Deploy from a branch**、*Branch* を **main / (root)** にして **Save**
7. 1〜2分待つと、同じ Pages の画面にURLが表示されます

```
https://<アカウント名>.github.io/pitch-lab/
```

このURLを選手に配ってください。スマホでもPCでも開けます。

**更新するとき**：リポジトリの `index.html` を開いて鉛筆アイコン → 中身を差し替え → Commit。
または **Add file → Upload files** で同名ファイルを上げ直せば置き換わります。1〜2分で反映されます。

> Public リポジトリなので、URLを知っている人は誰でも開けます。選手のデータはそれぞれの端末に保存されるだけなので、他人に見られることはありません。
> 非公開にしたい場合は、Cloudflare Pages や Netlify でアクセス制限をかけるか、学校・チームのサイト内に置いてください。

## 2. 他の選択肢

| 方法 | 向いている場面 |
|---|---|
| **Cloudflare Pages / Netlify** | フォルダをドラッグするだけで公開できる。アクセス制限をかけたいとき |
| **学校・チームの既存サイト** | 管理者に `index.html` を置いてもらう。一番手っ取り早いことも多い |
| **ファイルを直接配る**（LINE・メール・AirDrop） | 数人だけ／ネット環境が不安定な場所。ただし更新のたびに配り直し |

**Google Drive は不可です。** Drive は HTML をWebページとして表示する機能を廃止したので、リンクを開いてもダウンロードされるだけになります。配布用としては使えません（ファイルの受け渡しには使えます）。

---

## 3. チームの投手データを最初から入れておく

選手がリンクを開いた瞬間に、自分の球種が入っている状態にできます。

1. アプリを開いて、投手プロフィールを作る
   （CSV取り込み、実測値テーブル、どちらでも可）
2. ツールバーの **Make built-in roster** を押す
3. 出てきた1行をコピーする（クリップボードに入らない環境では、枠の中を選択してコピー）
4. `index.html` をテキストエディタで開く
5. **`const TEAM_ROSTER`** で始まる行を探す（ファイル中で1行だけです）
6. その行**まるごと**を、コピーした1行で置き換えて保存
7. アップロードし直す

これ以降、このURLを開いた人全員にそのロスターが入った状態で表示されます。更新したいときは同じ手順を繰り返してください。

なお、すでに自分でデータを作っている選手の端末では、**その選手の保存データが優先されます**（ロスターで上書きされません）。ツールバーの **Reset** を押すと、組み込みロスターの状態に戻ります。

## 4. 選手への説明（そのまま転送できます）

> **Pitch Lab の使い方**
>
> リンク：（ここにURL）
>
> - スマホよりも **タブレットかノートPC** のほうが見やすいです
> - 入力したデータは **自分の端末に自動保存** されます。次に開いたときも残っています
> - 端末を変えるとき・コーチに渡すときは、上の **Export (.json)** でファイルに保存して、相手側で **Import**
> - **Reset** は全部消して最初の状態に戻すボタンです。押す前に Export しておくこと
> - Rapsodo の CSV は上の **Import an arsenal from a Rapsodo (or other) CSV** から取り込めます
> - 単位はインチ・フィート・mph です
> - 画面下の **How to read this** に、回転・リリース・トンネルの解説が全部入っています

## 5. 既知の制限

- **スマホ幅（390px）では横スクロールが出ます。** タブレット（820px）ではほぼ問題ありません。スマホ中心で使うなら、スマホ最適化を入れたほうがいいです。
- 保存先は **端末ごと・ブラウザごと** です。同じ選手が別の端末で開くと中身は別になります。共有したい場合は Export / Import を使ってください。
- プライベートブラウズやブラウザ保存が無効な環境では自動保存されません。その場合は画面右上に **「Not saving」** と表示されます（アプリ自体は普通に動きます）。
- 全員のデータを1か所に集める機能はありません。それが必要な場合は別の作りになります。
